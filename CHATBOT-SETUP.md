# FAST-TRACK AI Career Assistant setup

## Included
- `chatbot.html`, `chatbot.css`, `chatbot.js`: responsive dark-theme chat interface, prompt shortcuts, local conversation history, and helpful fallback guidance.
- `api/chat.js`: Vercel serverless endpoint that calls the OpenAI API without exposing the API key in browser code.
- Candidate dashboard navigation link to the assistant.

## Enable real AI replies on Vercel
1. In the Vercel project, open **Settings → Environment Variables**.
2. Add `OPENAI_API_KEY` with your secret API key. Do not put this key in HTML or JavaScript.
3. Optionally add `OPENAI_MODEL` (defaults to `gpt-4o-mini`).
4. Redeploy the project.
5. Open `/chatbot.html` and send a test message.

Without `OPENAI_API_KEY`, the UI remains usable in guidance mode, but responses are local rule-based suggestions, not generated by an AI model.

## Important production note
Before public production use, add Firebase ID-token verification and per-user/IP rate limiting to `api/chat.js`, and review privacy/retention requirements. The endpoint validates request shape and keeps the provider key server-side, but it does not yet authenticate callers. The assistant is not connected to private Firestore job, profile, or application data; it must not claim to look up live records.
